### Игнорируемые файлы (.gitignore)

Благодаря добавленным файлам `.gitignore`, в репозиторий не попадут следующие типы файлов:
- **В каталоге `terraform/`**:
  - `.terraform/` — локальный кэш загруженных провайдеров и модулей.
  - `*.tfstate` и `*.tfstate.*` — файлы состояния инфраструктуры. **Критично для безопасности:** они часто содержат чувствительные данные (пароли, ключи API) в открытом виде.
  - `*.tfvars` и `*.tfvars.json` — файлы с переменными, которые также могут содержать секреты и не должны храниться в открытом доступе.
  - `.terraform.tfstate.lock.info` — временные файлы блокировок состояния.
  - `crash.log` — логи сбоев Terraform.
  - `.terraformrc` / `terraform.rc` — локальные конфигурационные файлы CLI.
